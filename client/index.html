      Get a Xiaohongshu Cookie

      TREK runs on your Linux server. Do not log into Xiaohongshu on that server. Copy the Cookie from a normal browser on your own computer or phone, then paste it into plugin settings.

      1. Log in on your own device

      Open www.xiaohongshu.com in Chrome or Firefox on your laptop or phone and log in. A headless Linux server has no QR-scan surface and is a poor place to keep a personal session.

      2. Copy the Cookie

      DevTools → Network → any edith.xiaohongshu.com request → Headers → Request Headers → Cookie. You can also use Application → Cookies. The value must include a1 and web_session.

      a1=…; web_session=…; xsecappid=xhs-pc-web
      3. Paste into TREK

      In TREK: Settings → Plugins → AI 攻略 → 小红书 Web Cookie. Save, then run “测试小红书会话”. The Cookie stays on the plugin server and never enters this page or the AI prompt.

      IP mismatch and 461

      The Cookie is used from the TREK server’s public IP, not your laptop’s. A home/phone login (IP1) reused on a cloud host (IP2) often triggers 461. Run “Test Xiaohongshu session” after saving. If it 461s, skip keyword search and paste links or note text instead — those paths do not need a Cookie.

      If your only computer is Linux

      Use a desktop Linux session with Chromium/Firefox — not the TREK Docker/host. SSH port-forwarding a GUI browser is fine; running a headless login bot on the server is not. Cookie lasts about a week; refresh when search starts failing.
