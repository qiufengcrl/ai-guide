# AI 攻略 — 未来功能规划

> 文档版本：2026-09-05  
> 基线版本：**v1.1.30**  
> 用途：汇总竞品调研结论与内部改进方向，供产品确认「做 / 不做 / 延后」。

---

## 1. 当前能力基线（v1.1.30）

以下能力**已实现**，本文档不再重复规划：

| 能力 | 说明 |
|------|------|
| 多输入源 | 目的地表单、小红书链接、粘贴正文、可选关键词搜索 |
| 地点提取 | LLM 从攻略中提取候选地点、预约标记、必去景点 |
| 地理编码 | Places API bridge / Nominatim；别名表；停车场/公交站降权 |
| 行程编排 | 按天分组、区域聚类、同天距离排序 |
| 可编辑预览 | 按天/地点勾选，确认前不写库 |
| 写入 TREK | commit 创建真实行程、地点、日程 |
| 任务恢复 | job 持久化；GET /plan 异步轮询，不阻塞网关 |
| 隐私 | xhs_cookie 仅存服务端，不进 iframe / AI / 导出 |
| 来源追溯 | 每条地点可关联来源笔记 |
| 限流与容错 | CUQPS 退避、30 分钟超时、瞬态错误 warning |

**核心差异化**：多数开源项目止步于 HTML/Markdown 攻略页；我们是 **小红书 → 可编辑预览 → TREK 真实行程** 的闭环。

## 3. 候选功能清单

每项包含：**编号**、**简述**、**用户价值**、**改动范围**、**复杂度**、**依赖/风险**、**参考项目**、**建议优先级**。

复杂度：`低` / `中` / `高`  
建议优先级：`P0` 建议先做 / `P1` 体验深化 / `P2` 长期可选

> **请在第 5 节勾选确认**，或直接在 PR/Issue 中回复编号。

---

### F01 — 多维度小红书搜索

| 项 | 内容 |
|----|------|
| 简述 | 除「{目的地} 攻略」外，并行搜索避坑、费用、美食、拍照机位等 query 模板，合并去重后进入提取流程 |
| 用户价值 | 信息更全面，减少漏掉避坑/价格线索 |
| 改动范围 | `server/pipeline.js`（搜索编排）、`server/xhs/`、`max_notes` 配额分配 |
| 复杂度 | 中 |
| 依赖/风险 | 增加 XHS 请求量，需与现有限流策略协调 |
| 参考 | travel-planner-skill、On-The-Road |
| 建议优先级 | **P0** |

---

### F02 — 笔记质量评分与广告过滤

| 项 | 内容 |
|----|------|
| 简述 | 对搜索/链接抓取的笔记打分，过滤营销帖（跟团、私信、定制游等），优先个人真实体验 |
| 用户价值 | 提取质量提升，减少「广告景点」进入行程 |
| 改动范围 | `server/pipeline.js`（`evidenceFromSearch` 前后）、规则 + 可选 LLM 轻量分类 |
| 复杂度 | 低～中 |
| 依赖/风险 | 规则需持续维护；过度过滤可能丢掉有用帖 |
| 参考 | On-The-Road |
| 建议优先级 | **P0** |

### F03 — 地点间导航链接

| 项 | 内容 |
|----|------|
| 简述 | 预览页每个地点或相邻站点生成一键导航：国内高德 URI / 网页，国际 Google Maps Directions |

| 参考 | On-The-Road、xiami |

### F04 — 地理边界确定性校验

| 项 | 内容 |
|----|------|
| 简述 | geocode 后用 Haversine 校验：坐标距目的地中心超过阈值（如 150km）则拒绝或降权；结合目的地上下文消歧 |
| 用户价值 | 减少同名异地、跨省误匹配（如「故宫」匹配错城） |
| 改动范围 | `server/geo/nominatim.js`、`server/pipeline.js` |
| 复杂度 | 低～中 |
| 依赖/风险 | 阈值需按国内/国际/岛屿等场景调参 |
| 参考 | Navoryn |
| 建议优先级 | **P0** |
