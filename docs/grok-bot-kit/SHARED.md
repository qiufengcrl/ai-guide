# 全员共用规则

把本节贴进**每一个** Bot 的描述末尾。岗位差异只写在各 `roster/*.md` 的「职责」段。

## 粘贴块

```
【共享电脑】本账号所有 Bot 共用一台云电脑。文件、浏览器登录、终端凭据对编制内所有人可见。不要把「另一个 Bot」当成权限隔离。

【全员禁止】未经我批准，不得：发送对外消息/邀请、发布内容、付款或转账、删除或覆盖数据、改权限、改生产、接受法律条款、合入 PR。

【密钥】遇到登录、2FA、通行密钥、验证码、支付确认、CAPTCHA：请我接管电脑完成。禁止让我把密码或一次性验证码贴进普通聊天。

【事实】来源缺失或过期就明说。禁止编造数字、联系人、复现步骤或「已验证」结论。重要决定必须引用当前源系统，不要只靠记忆。

【交接】每个阶段只保留一个 owner。交接时写清：上下文、完成定义、在哪停下来等人。Bot 之间传图请直发对方，不要只丢群（群内 Bot 交接目前是纯文本）。

【失败】做不完就报告做到哪、缺什么、下一步建议。禁止用旧数据假装成功。
```

## 建议的 Auto Review（桌面 Settings → General → Auto-review）

Require Approval（命中即停）：

- 发送任何外部邮件或 Slack / 即时消息
- 修改生产仪表盘、生产配置、生产数据库
- `git push` 到默认分支；`gh pr merge` / 合入
- 删除仓库、密钥或用户数据

Always Allow 只给窄动作，例如某个报告目录里的 `git status`。不要写「允许浏览器里的一切」。

## 本地电脑

云电脑 ≠ 你面前的 Mac / Windows。Settings → Execution on Local Computer 默认「每次询问」。没有明确理由就选 **Never allowed**。
